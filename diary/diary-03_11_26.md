A first finding while writing the test: when any connector may be requested,
the direct connector from input to goal is always a single gap, so the fewest
missing connectors is never more than one. Multi-step repairs matter only when
an acquirer refuses connectors, and `Repair` is therefore relative to the
allowed ones; `repair` re-plans around each refusal.

Prediction, before running. Same 40-type setting, but tasks are now any
unreachable goal, not only those with a single repairable gap. With data for
10% of pairs, a given task has a single-gap repair with data only if one of
its roughly |producible|·|co-reachable| gaps has data; with sparse libraries
these sets are small, so `repair1` should repair only about half the tasks.
`repair3` should repair nearly all, with requests in the tens and a few unused
acquisitions per task from partial routes abandoned after a refusal. `random`
should repair nearly all but with hundreds of requests and tens of unused
acquisitions. Accuracy should fall with the number of learned connectors on a
route, about 0.98 per learned hop.

Measured multi-step result (seeds 3704–3706, 40 unreachable tasks each), per
task, mean ± sample standard deviation over seeds:

| Policy | Requests | Acquisitions | Unused | Repaired | Accuracy |
|---|---:|---:|---:|---:|---:|
| repair1 | 6.9 ± 1.2 | 0.53 | 0.0 | 53% ± 4% | 0.981 ± 0.003 |
| repair3 | 19.0 ± 6.1 | 1.75 ± 0.63 | 0.30 ± 0.25 | 94% ± 10% | 0.974 ± 0.007 |
| random | 418 ± 46 | 41.5 ± 1.9 | 38.9 ± 2.1 | 100% | 0.953 ± 0.002 |

All predictions held. Single-connector repair fixed 53% of unreachable tasks;
allowing three raised that to 94% at 19 requests and 1.75 acquisitions per
task, 0.3 of them unused after refusals. Random acquisition repaired every task
but needed 22× the requests and 24× the acquisitions (about 10,600 labels per
task against 450), 94% unused, and its routes, composing more learned
connectors, were less accurate (0.953 against 0.974). The 6% that `repair3`
missed need more than three connectors with data. New intermediate types are
not invented; every connector joins existing types.
